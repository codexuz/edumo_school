# A Complete Guide to Multilevel Writing

The Uzbek Multilevel (CEFR) writing paper, trained part by part: the paper explained in Uzbek,
the official band descriptors, an examiner-marked script, then twenty full practice exercises
with model answers, trilingual word lists and vocabulary and sentence practice. A4, 178 pages.

The palette is the Impulse vocabulary books' (`--blue:#1E90FF` / `--blue-d:#0B63CE` /
`--navy:#0A2A5E`, Inter); the page model and the cover are the Multilevel Practice Book's —
fixed 210×297mm sheets with their own running header and footer, content flowing through two
columns, and a white sheet + blue band cover carrying a 3D hero and Uzbek girih ornaments.

Rebuilt from `A Complete Guide to Multilevel Writing` (the source PDF in `src/`).

Each exercise gives one situation and three tasks: Task 1.1 (informal email, ~50 words, 5 marks),
Task 1.2 (formal email, 120–150 words, 6 marks) and Task 2 (discussion post, 180–200 words,
6 marks), and runs to eight pages:

1. **Tasks** — the prompt letter, Task 1.1, Task 1.2, Part 2 and Task 2 as a single card, and a
   planning box.
2–5. **Lined answer pages** — one each for Task 1.1 and Task 1.2, two for Task 2.
6. **Model answers, Part 1** — the two emails side by side, then the 20-item word list.
7. **Model answer, Part 2** — the discussion post flowing across both columns, then its word list.
8. **Practice** — four tasks on the unit's language (see below).

Word lists are **English · Russian · Uzbek**: 40 items per exercise, 800 in the book.

### Practice pages

| Task | What it is | Where it comes from |
|---|---|---|
| A | Complete the sentence (8 gaps) | sentences from that unit's model answers |
| B | Match English to Uzbek (8 items) | that unit's word lists |
| C | Choose the English word (6 items, Russian prompt) | that unit's word lists |
| D | Make it formal (5 sentences) | hand-written in `data/sentences.json` |

A, B and C are generated by `scripts/practice.py` from the unit's own data, seeded on the
exercise number so the book is reproducible. Answers to all four are in the key at the back.

## Build

```
./build.sh     # -> dist/Multilevel_Writing_Guide.pdf and dist/Writing_Cover_spread_A4.pdf
```

Requires Python 3 with `pypdf` and `qrcode`, Node with Playwright (Chromium) and poppler-utils.

The build is: `check.py` → `build.py` (interior HTML) → `render.js` (interior PDF) →
`cover.py` + `cover_render.js` (the A3 cover) → `merge.py` (cover scaled to A4, wrapped around
the interior, plus the print spread).

`build.sh` runs `scripts/check.py` first, so the build fails if any model answer falls outside its
word band, a word list is not exactly 20 complete triples, or a practice task cannot be derived.
Because each sheet is a fixed-size box, `scripts/render.js` measures every column box and reports
any page whose content would be clipped.

- Content: `data/*.json` — format in `SCHEMA.md`. Nothing in `scripts/` needs editing to change text.
- Design: `scripts/style.css`. `scripts/build.py` emits `dist/cover.html` + `dist/body.html`;
  the cover is printed separately so the running header and page number stay off it.

## Changes made to the source material

### Model answers

Every one of the 60 model answers (30 rebuilt from the source, 30 written for the new Exercises
11–20) sits inside the word band its own task asks for. In the source, most Task 1.2 answers ran 150–210 words against a 120–150 ceiling and
most Part 2 answers ran 205–220 against 180–200 — a model answer that breaks the rubric teaches
the wrong lesson. They are now 51–58 / 122–137 / 180–200 words, verified on every build.

Specific faults fixed:

- **Exercise 1, Task 1.1** — the letter was addressed "Hi Alex" and signed "Alex", so the writer
  and the recipient were the same person. It also answered only half the task: it gave feelings
  but suggested visiting a coffee shop instead of saying what the library should do. Rewritten.
- **Exercise 6, Task 1.1** — ended "Talk soon," with no name. Signature added.
- **Exercise 8, Task 1.1** — contained "Let's discuss about this", which a model answer should
  not teach. Rewritten.
- **Exercise 9, Task 1.2** — opened "Dear The Manager". Now addressed to a named manager.
- **Sign-offs** — made to follow one rule throughout: a named person or title-holder takes
  *Yours sincerely*, a role or department with no name takes *Dear Sir or Madam* / *Yours
  faithfully*. Exercises 3, 5 and 7 changed accordingly, and the rule is stated on page 74.

### Task prompts

- Exercise 9: "you are unemployment" → "you are currently unemployed".
- Exercise 8, Part 2: "Should students not be allowed to use smartphones at schools?" → "Should
  students be banned from using smartphones at school?" (the double negative made the stance
  impossible to state cleanly).
- Exercise 10, Part 2: the question was ungrammatical ("…or traditional subjects like math and
  science are important?") and has been rewritten as a straight either/or.
- Exercise 4, Part 2: "impacts" → "impact".
- Exercises 5, 7, 8 and 10: the prompt letter and the tasks were printed run together in one
  block; they are now separate elements. Exercise 8's prompt letter was also lightly corrected
  ("your disturbance made some inconveniences for me").
- British spelling used consistently (neighbourhood, centre, organise). US spellings are kept
  verbatim where they appear inside the official band descriptors and Exercise 1's prompt letter.

### Vocabulary lists

Standardised at exactly 20 English–Uzbek pairs per task, drawn from the model answers.

- Many source entries had lost their spaces in the PDF (`Bestregards-Engyaxshitilaklarbilan`,
  `Welcomeexperience-Qarshiolishtajribasi`); all re-spaced.
- Exercise 3 listed 30 items with "Onboarding process" twice; Exercise 6 had 10 items plus a
  separate 9-item "Phrases/Collocations" block. Both merged and trimmed to 20.
- Mistranslations corrected: "Perceive — ishonmoq" (to believe → *idrok qilmoq*), "Relaxed
  opportunity — Noyob imkoniyat" (*noyob* = rare), "Eager to discuss — Muhozakaga intilish"
  (*Muhokamaga*).

### Guide and apparatus

- The Uzbek guide had several paragraphs with their spaces lost in the PDF
  (`Bubo'limdanomzodumumiyqiziqishuyg'otadiganmavzuasosida`); all restored.
- Marked script, Task 2: the examiner's comment read "The response is relevant, but the stance is
  clear"; the contrastive "but" is a slip and is printed as "and".
- The band descriptor tables are reproduced in full. The source highlighted rows in green without
  a stated meaning; here the tint marks the bands the book trains you to reach, and the key says so.


## Cover

`scripts/cover.py` builds the cover in the Impulse style shared with the Multilevel Practice
Book: a white sheet, a blue band clipped to a curve, a 3D hero, SVG girih ornaments and a star
frieze, with the title block beneath. It is drawn at A3 and scaled to A4 by `merge.py`, which is
what gives the type its density.

- `assets/brand/hero.png` — the 3D hero: an open notebook, fountain pen, envelope, paper stack
  and approval badge, generated with OpenAI's image model (`gpt-image-2.5-sunburst`, via Figma
  AI) in the book's blue palette, then matted off its background by `scripts/cutout.py`.
  The prompt asks for **no cast shadow on a pure white ground**: a render with a contact shadow
  mattes badly, leaving a pale halo on the blue band that cannot be keyed out without eating the
  artwork's own white paper.
- `assets/brand/logo_blue.png`, `icon_blue.png`, `icon_white.png` — shared with the practice book.
- The back cover carries the blurb and a QR code to the Telegram channel; the spine is drawn only
  in the spread. **Set `SPINE_MM` in `scripts/cover.py` to the printer's measured spine width** —
  it is 13 mm at A3 (≈9 mm at A4) for 179 pages on 80 g/m² paper.
- Unlike the practice book, the cover uses Inter and Inter Display rather than webfonts, so it
  matches the interior and needs no network at build time.

`dist/Writing_Cover_spread_A4.pdf` is the back + spine + front spread for the printer.

## Beyond the source

The source PDF covered ten exercises with Uzbek-only word lists and no practice. This book adds:

- **Exercises 11–20** — ten further papers on new situations: a delayed online order, a bus
  timetable change, a cancelled school trip, a workplace dress code, a noisy building site, a
  sports club short of volunteers, a university course moving online, a restaurant asking for
  feedback, a building recycling scheme and an offer to work abroad. Thirty more model answers,
  all within band.
- **Russian** alongside Uzbek in every word list.
- **A practice page per unit** with an answer key, so each unit can be set as homework.
- **A second lined page for Task 2**, which 180–200 words needs.
- **Part 2 and Task 2 presented as one card**, matching how the paper actually reads.
- **A planning box** on every task page.
